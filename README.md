## 🔧 Frequently Asked Questions

**Does the software work on every server?**
Most servers allow client-side visual mods. Some servers block external tools to ensure a specific experience. If the menu does not appear, the server likely restricts it.

**Will this software trigger an antivirus warning?**
Some antivirus programs flag software that reads game memory. This is common for game overlays. You may need to add an exception for SkriptGG in your antivirus settings if the program fails to launch.

**Can I get banned from FiveM?**
SkriptGG acts as a local tool. It does not hack the game server directly. Follow server rules to keep your account safe.

**How do I uninstall the software?**
